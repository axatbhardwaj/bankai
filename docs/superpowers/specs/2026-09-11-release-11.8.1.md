# Haoshoku 11.8.1 Release Acceptance

## Objective

Prepare an immutable local 11.8.1 candidate that combines the reviewed,
driver-neutral advisor routing changes with stable commit
`cd63f6ecf07b497dc06863903b12fc1d5ac8b11c` and its Hermes relay integration.

## Included versions

- Haoshoku package and CLI: `11.8.1`
- Merged stable baseline: `cd63f6ecf07b497dc06863903b12fc1d5ac8b11c`
- Hermes relay source: `paseo-hermes-relay` v0.2.0 at
  `73846214657a165379a1698b6bccff6c9c9e484f`

The existing 11.8.0 changelog entry remains the source of truth for the relay
integration. The 11.8.1 entry covers only the advisor-routing patch.

## Boundaries

This preparation changes repository files and local commits only. It does not
push, create a PR or tag, publish a GitHub or npm release, install a package,
sync live profiles or skills, alter credentials or access, or touch host
services. Human publication authority and independent Opus review remain
unchanged.

## Verification

The final candidate must pass the full Bun test suite and lint, report 11.8.1
from the repository CLI, pass `git diff --check`, and produce a dry-run package
that contains the Hermes relay helpers and technical-advisor policy.
